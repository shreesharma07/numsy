**Numsy** validates, sanitizes, extracts and de-duplicates Indian mobile numbers from text, CSV and Excel. One engine powers four ways to use it, so they always agree.

| Surface | Use it for | Start with |
| --- | --- | --- |
| **Library** | A typed API inside your Node.js app | `npm install numsy` |
| **CLI** | Cleaning files from the terminal or CI | `npx numsy@latest --help` |
| **Local dashboard** | A browser UI on `localhost:6789` | `numsy dashboard --open` |
| **Playground** | The dashboard, entirely in your browser | [Playground](https://numsy.pages.dev/playground/) |

<a id="features"></a>

## <img src="assets/icons/supported.svg" width="22" alt="" /> Features

*Turn messy contact data into clean, unique, valid Indian mobile numbers.*

| Capability | What it does |
| --- | --- |
| **Validate** | Accepts 10-digit numbers starting with 6, 7, 8 or 9; rejects repeats, sequences and dummies |
| **Sanitize** | Strips spaces, punctuation and the `+91` / `0` prefix |
| **Extract** | Finds every number in free text |
| **De-duplicate** | Keeps all, the first or the last occurrence of each number |
| **Read** | CSV, Excel, plain text or stdin, with phone and name columns detected for you |
| **Export** | CSV, Excel, JSON, Markdown and Text |

<a id="quick-start"></a>

## <img src="assets/icons/quickstart.svg" width="22" alt="" /> Quick start

*Validate a few numbers, clean a whole sheet, or call the engine from code.*

### CLI

| Command | Does |
| --- | --- |
| `numsy validate <numbers…>` | Validates each value |
| `numsy extract <text…>` | Finds every number in free text |
| `numsy process <file>` | Cleans a `.csv` or `.xlsx` file and exports the results |
| `numsy dashboard` | Starts the local dashboard and REST API |
| `numsy formats` | Lists the output formats |

```bash
numsy validate 9876501234 "+91 98765 43210"
numsy process contacts.xlsx --dedupe --only valid -f csv,xlsx -d reports
```

### Library

```ts
import { Numsy } from 'numsy';

const numsy = new Numsy({ enableLogging: false });
numsy.validate('+91 98765 01234'); // → { sanitized: '9876501234', isValid: true, … }

const report = await numsy.analyzeFile('contacts.xlsx', { dedupe: 'first' });
report.analytics; // → { totalValidNumbers, uniqueValidNumbers, duplicatesRemoved, … }
```

> [!TIP]
> Every flag, method and exit code is in the [CLI guide](docs/guides/cli.md) and the [Library guide](docs/guides/library.md).

<a id="local-dashboard"></a>

## <img src="assets/icons/rest.svg" width="22" alt="" /> Local dashboard

*`numsy dashboard` opens a browser UI on [`localhost:6789`](http://localhost:6789): drop in a file of up to 50 MB, filter it and export the rows you need.*

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="assets/screens/dashboard-dark.png" />
    <img src="assets/screens/dashboard-light.png" alt="Numsy dashboard showing 1,200 sample rows with valid, invalid, unique and duplicate counts" width="100%" />
  </picture>
</p>

| Area | Options | CLI flags |
| --- | --- | --- |
| Filters | Duplicates, dummy numbers, empty cells | `--dedupe` `--loose` `--skip-empty` |
| Columns | Detected or chosen phone and name columns | `--column` `--name-column` |
| Rows | All, valid, invalid, unique or duplicates | `--only` |
| Output | Number style, columns, header and row limit | `--number-style` `--columns` `--max-rows` |
| Export | CSV, Excel, JSON, Markdown, Text | `-f` |

> [!NOTE]
> The dashboard listens on `127.0.0.1` only, keeps uploads in memory and makes no requests to the internet. It also serves a [REST API](docs/guides/rest-api.md) for scripts.

<a id="performance"></a>

## <img src="assets/icons/tests.svg" width="22" alt="" /> Performance

*About 1.1 million validations per second.*

| Workload | Time |
| --- | --- |
| Validate 100,000 numbers | **89 ms** |
| Validate 1,000,000 numbers | **0.82 s** |
| Analyse and de-duplicate 500,000 rows | **1.8 s** |
| Real 11.7 MB Excel file, 505,277 rows | **8.7 s** to read, **2.2 s** to analyse |

> [!NOTE]
> Measured on an AMD Ryzen 7 laptop with Node.js 24. The [Performance guide](docs/guides/performance.md) has the method and shows how to run `node scripts/benchmark.js` yourself.

<a id="privacy"></a>

## <img src="assets/icons/standards.svg" width="22" alt="" /> Privacy

*Numsy never receives your data. Every surface runs on your computer or in your browser.*

<p>
  <img height="20" src="https://img.shields.io/badge/storage-none-0B7A4B?style=flat" alt="No storage" />
  <img height="20" src="https://img.shields.io/badge/sharing-never-0B7A4B?style=flat" alt="Never shared with third parties" />
  <img height="20" src="https://img.shields.io/badge/AI%20training-never-0B7A4B?style=flat" alt="Never used for AI training" />
</p>

| Surface | Runs on | Your data |
| --- | --- | --- |
| Library | Your Node.js process | Stays in your process |
| CLI | Your terminal | Read from and written to your disk |
| Local dashboard | `127.0.0.1:6789` | Kept in memory, never sent out |
| Playground | A Web Worker in your browser | Never uploaded |

> [!IMPORTANT]
> Numsy does not store file contents, never sells or shares them, and never uses them for AI training. Read the [privacy & data disclaimer](https://numsy.pages.dev/privacy/).
